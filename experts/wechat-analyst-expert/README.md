# 微信公众号数据分析师 · 知衡

WorkBuddy 单专家包，行业分类为数据智能。专家复用 IRSS 已授权工作空间中的订阅、文章及阅读量快照。需要 Node.js 22 或更新版本，运行时由内置技能调用 CLI。

召唤后可选择推荐对标账号、分析近 30 天高表现文章、对比两个公众号的选题。未指定账号时从现有订阅中选择。数据覆盖与原文链接随结果给出。

构建时从 ai-rss 仓库打入现有 wechat-data-analyst 技能及 CLI。在仓库根目录运行 python scripts/package-expert.py。上传开放平台时选择「专家」类型。

开源许可为 MIT。
