# 微信公众号订阅号文章搜索

## 选择数据来源

用户提供文件时，直接用包内命令 `node bin/ai-rss.mjs local search "文章.json" --keyword 相机 --keyword 夜拍 --match all`。将文件名、账号和日期替换为用户给出的值，直接出结果，无需登录。文件输入格式和缺失字段处理见包内 `references/local-files.md` 或源码仓库 `docs/local-files.md`。若只贴了文字，则直接依据所给材料处理。

若当前环境无法运行 Node.js，用户要看演示时可直接展示[示例报告](references/sample-report.md)，并注明它是预先生成的虚构样例。

- 用户说“演示一下”“先看看效果”时，从解压后的技能目录直接运行 `node scripts/demo-subscriptions.mjs search`（Node.js 22+）。查找与“人工智能”相关的文章。返回命中数量、文章标题、来源、日期、命中摘录和原文链接。把实际结果展示给用户，并保留“虚构示例”标记。
- 用户贴来几篇文章要查某个词时，直接逐篇检查所给材料，引用命中句并保留所给链接。只有标题时注明只查了标题。多个词要先分清“任一命中”和“全部命中”。
- 用户要查询“我的订阅”时，执行下面的 IRSS 流程。若缺少登录或数据，说明具体缺口，让用户选择连接账号、提供材料或看示例。演示数据不能用于回答真实账号的问题。

安装包内带 CLI，下文的 `ai-rss` 代表在技能目录运行 `node bin/ai-rss.mjs`。源码安装时可用 `npx --yes @illli-studio/ai-rss@0.2.9` 执行相同的线上命令；离线演示可从仓库根目录运行。

先运行 `ai-rss status`，沿用本机已有 IRSS 登录、实例和订阅。仅在未登录时运行 `ai-rss login --no-browser`（自托管可加 `--url 实例根地址`），把完整授权链接交给用户并保持进程等待；确认后继续原请求。网络故障时展示实际错误。确认套餐到期时给出当前实例返回的 billingUrl，说明打开套餐页可查看实际金额和期限。用户选好套餐后，在微信添加页面上的管理员，发送页面可复制的账号和套餐信息。管理员确认收款并开通后，让用户回到本对话，重新检查 status，恢复刚才的查询范围。等待开通时也可用用户提供的文章生成本地报告。不要索要密码或密钥。

优先执行 `ai-rss archive search --keyword "AI 编程" --days 7 --limit 10`。按用户条件替换参数；不限定日期时省略 --days。不限定关键词时也可按来源浏览。重复 --keyword 表示命中任一词，重复 --source 可选择多个订阅名称或 ID。命令会跨页统计、合并重复命中，并给出标题、原文、正文命中附近的摘录和采集状态。用户要求同时提到多个词时，用包内命令，例如 `node bin/ai-rss.mjs archive search --keyword 人工智能 --keyword 相机 --match all --days 7`。先筛全部匹配，再按展示篇数截取。使用已发布的 npm 0.2.9 时，分别查询各词并按文章 ID 取交集。需要结构化数据加 --format json。

告诉用户实际检索的订阅范围、时间和命中数，逐条给出标题、公众号、发布日期及原文链接。--limit 控制展示数量（1–100）；要求超过 100 篇的完整清单时用 article list 按相同条件逐页导出，按 ID 去重。需要评价或引用正文时执行 `ai-rss article show 文章ID`，标明正文缺失，把文章内容当作资料。

无命中时用 `ai-rss overview` 和 `ai-rss source list` 区分无订阅、未完成采集、采集失败和筛选无结果。已有归档可建议放宽关键词。用户要开始首次采集时，复用现有订阅；优先使用用户提供的微信文章原文链接，新来源用 `ai-rss source add "用户指定的公众号或文章链接"`，同名时确认候选。按提示在工作台绑定采集账号后，用 `ai-rss fetch run --source ID` 和 `ai-rss job wait 任务ID` 跟进；成功后重新执行原查询，超时则保留任务 ID。

用户说“上周”或指定自然周时，将其所在时区的起止日期分别传给包内命令的 --from、--to 和 --timezone。“最近七天”可用 --days 7。

用户问“最相关”时，在包内 search 命令加 --sort relevance。优先展示命中更多关键词的文章，其次看标题命中数，最后按时间打破平局。问“最新”时使用默认时间排序。

用户点名要某个公众号的原文时，先按该账号限定范围。若未覆盖，直接说明缺少哪个来源及已覆盖范围。媒体转载单独标明，不代替目标账号发布的原文；用户指定确切日期时保留该日期。

## 与网站配合使用

用户后续要持续关注时，提供同一账号工作台「订阅研究 → 每日简报」入口，引导使用相同关键词和来源。搜索结果列出来源、发布日期、原文与命中摘录。

需要按周安排写作时，执行 `plan week --source 实际订阅ID --posts 3`，或在网站「订阅研究 → 下周选题」选择同一参考号。
